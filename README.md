A single-word entry for the make.fun bounty **One Word, First Thought**: the first word
that came to mind, written here as one plain word, no topic and no second draft. The
program writes that word to `/output/entry.txt` as UTF-8 with no trailing newline, so the
file is exactly one word of 1 to 24 code points and passes the gate.

**The word:** `snickersnee` — an old stage-word for a long knife, and the first half of it
is a laugh. You see the blade and hear the snigger in the same breath.

## Run it

```bash
python3 main.py
cat /output/entry.txt
```

Deterministic: no network, no randomness, no arguments. Each run writes the same bytes.
